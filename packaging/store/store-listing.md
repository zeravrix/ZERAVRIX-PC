# Microsoft Store listing draft — ZERAVRIX

## App name

ZERAVRIX

## Short description

A native Windows reader for manga, manhua, and manhwa with built-in sources, offline downloads, library progress, and a focused low-overhead reading experience.

## Full description

ZERAVRIX is a native Windows x64 manga, manhua, and manhwa reader built for comfortable desktop reading. Browse supported source catalogues, open detail pages, review chapter lists, read pages in the in-app vertical reader, save chapters for offline use, and continue from the last page you read.

The Store Edition is intentionally focused. It ships only bundled, non-adult source adapters and permanently excludes adult-labelled sources and custom third-party artwork themes. It does not download or execute remote source extensions. When a source requires a CAPTCHA or manual verification, ZERAVRIX opens that source in the user’s default Windows browser; verification is completed by the user, with no automated CAPTCHA bypass.

## Key features

| Feature | Description |
|---|---|
| Catalogue browsing | Browse the latest and searchable manga, manhua, and manhwa items exposed by supported bundled sources. |
| Details and chapters | Open cover art, description, metadata, chapter dates, and ordered chapter lists. |
| In-app reading | Read chapter pages in the native Compose Desktop reader with ordered loading, zoom, progress saving, and next-chapter navigation. |
| Offline downloads | Download selected chapters or complete available reading sets and open them without network access. |
| Library and history | Keep favourites, reading history, latest-read chapter markers, and page-level resume progress on the device. |
| Performance focus | Uses persistent cover caching, bounded memory caches, background decoding, lazy network initialization, and a packaged Windows runtime. |
| Music | Optionally play user-selected local music and playlists while browsing or reading. |
| Languages | English, Arabic, and French interface options are included. |

## Safe-content notice

ZERAVRIX Store Edition permanently excludes adult-labelled source adapters and does not expose an adult-content toggle. Remote catalogue providers control the material they publish. Users should report inappropriate remote content to the provider and to the publisher contact listed in the privacy policy.

## System requirements

ZERAVRIX Store Edition is intended for Windows 10 version 1809 or later and Windows 11 on x64 hardware. The package includes its Java runtime and does not require Android, an emulator, or a separate Java installation. Network access is required for remote catalogue browsing, source page loading, and downloads; previously downloaded chapters remain available locally.
