# ZERAVRIX 1.4.0 Store Edition — release handoff

**Publisher:** U1M  
**Target:** Native Windows x64  
**Release label:** ZERAVRIX 1.4.0 Store Edition  
**Handoff date:** 24 August 2026

## Result

The Store-oriented refactor is complete in the active source tree. ZERAVRIX retains source-based catalogue browsing, search, details, chapter lists, ordered page reading, downloads, offline reading, Library, history, saved page progress, configurable Komga/Kavita connections, and local Music. The build remains Kotlin/JVM 21 with Compose Desktop and includes a native Windows x64 launcher plus a bundled Java runtime; it does not run an Android APK or emulator.

The Store Edition permanently excludes adult-labelled sources and custom third-party artwork themes. It removes dynamic executable extension loading and remote extension-store code from the active build. Verification uses the default Windows browser for user-completed CAPTCHA or access verification and does not automate bypasses. JavaFX WebView is not shipped.

## Verification

The complete Gradle build and test sequence passed after the final cleanup:

```text
:core:test
:source-api:test
:reader:test
:desktop-app:compileKotlin
:core:jar
:source-api:jar
:reader:jar
:desktop-app:jar
BUILD SUCCESSFUL
```

The regenerated native launcher was smoke-tested under Wine for 25 seconds and remained alive without JVM/native startup errors. The test result is recorded in `native-launcher-smoke-test.log`. This does not replace a clean Windows x64 installation, offline-reading, source-flow, suspend/resume, and uninstall/reinstall test.

The corrected MSIX is generated by Microsoft’s MSIX SDK and contains native `AppxManifest.xml`, `AppxBlockMap.xml`, and `[Content_Types].xml` components. The recommended `.msixupload` wrapper contains that MSIX package. Both archives pass structural ZIP validation, and the final staging scan found no active references or payload entries for JavaFX, the removed adult source, the removed custom themes, or dynamic extension loading.

## Important limitation

The replacement package is structurally valid and intentionally unsigned for Store submission; Microsoft re-signs MSIX packages during publication. The manifest now contains the exact case-sensitive values reported by Partner Center: `U1M.Zeravrix` and `CN=D7CFED99-F946-4B71-8F83-D7F3A1DD152D`. Upload the `.msixupload` file. Do not describe the package as Store-approved until Microsoft validation and certification complete.

The interactive EXE installer is included for internal testing only. It should not be submitted through the EXE/MSI route unless it is separately made silent and all applicable signing requirements are satisfied.
