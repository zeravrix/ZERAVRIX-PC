# ZERAVRIX Store Edition handoff

## What this build is

ZERAVRIX Store Edition is a native Windows x64 Kotlin/JVM plus Compose Desktop manga, manhua, and manhwa reader. It keeps source catalogue browsing, search, manga details, chapter lists, in-app page reading, downloads, offline reading, Library, history, progress resume, and local Music. It does not run an Android APK or emulator.

The application starts through a small native Windows x64 launcher and a bundled Java runtime. The latest payload uses lazy HTTP and crypto initialization, persistent cover caching, ordered page fetching, background image decoding, stable lazy-grid keys, and bounded cover memory caching to reduce startup failures and scrolling stalls on older hardware.

## Store-safe behavior

The Store Edition permanently forces `nsfwEnabled=false` when settings are loaded and saved. The adult source adapter is absent from the active source tree and the built-in registry. Legacy adult settings are ignored, and Store UI paths retain the safe-content filtering boundary for source, manga, library, history, and download presentation.

Spider-Verse, Alucard, Attack on Titan, and other custom third-party artwork themes are removed. The application uses the standard ZERAVRIX dark/light interface and the square ZERAVRIX logo. The optional local icon preference is separate from the removed artwork-theme system and does not alter the fixed MSIX package identity or tiles.

Remote extension repositories, user-installed source JAR loading, service-loader source providers, and the remote extension-store UI are removed from the active Store build. The built-in adapters are compiled with the application, so catalogue browsing, details, chapters, pages, and downloads do not depend on a remote code repository. Configurable built-ins such as Komga and Kavita retain their endpoint and credential preferences because they connect to servers selected by the user.

Manual source verification opens the user’s default Windows browser. The user completes CAPTCHA or other verification manually and may paste a Cookie header back into the application. ZERAVRIX does not automate or bypass CAPTCHA challenges and does not ship a JavaFX WebView.

## Important package limitation

The corrected package is generated by Microsoft’s open-source MSIX SDK and includes native `AppxBlockMap.xml` and `[Content_Types].xml` metadata. It is intentionally unsigned for Store submission; Microsoft re-signs MSIX packages during publication. The manifest now uses the exact package identity supplied by Partner Center: `U1M.Zeravrix` and `CN=D7CFED99-F946-4B71-8F83-D7F3A1DD152D`. If rebuilding on Windows, use `store/build-msix-on-windows.ps1` with the Windows SDK `makeappx.exe`; its defaults now preserve this identity.

The historical Inno Setup EXE and portable packages are not the Store deliverable. They may remain useful for internal testing, but the interactive installer should not be represented as the final Store package without separately satisfying the Store’s EXE/MSI signing and silent-install requirements.

## Owner actions before submission

U1M must complete Partner Center account and identity verification, reserve the product name, confirm package identity and publisher values, publish the final privacy policy, validate source and content rights, take clean screenshots from the final build, complete the age-rating questionnaire, run a clean Windows x64 installation and offline-reading test, and submit through Partner Center. Microsoft’s validation and certification decision is outside this build process.
