# Desktop controls

Default:
- Left/Right: previous/next page (direction-aware)
- PageUp/PageDown: previous/next page
- Home/End: first/last page
- Ctrl+MouseWheel: zoom
- Mouse drag: pan while zoomed
- F: fullscreen
- Fit: reset zoom to fit
- 1: single-page
- 2: double-page
- A: automatic page mode
- Esc: leave fullscreen / close reader overlay

Controls should be configurable later.
